# Поля юридического реестра

## Обязательные поля

| Поле | Содержание |
| --- | --- |
| ID | Уникальный внутренний идентификатор записи |
| Клиент | Лицо, чьи интересы представляет Евгений |
| Контрагент или оппонент | Вторая сторона либо орган |
| Тип вопроса | Суд, договор, претензия, компания, объект, административный вопрос |
| Наименование | Краткое понятное название дела или задачи |
| Номер | Номер дела, договора, требования или иного документа |
| Предмет | Одно предложение о сути вопроса |
| Сумма | Сумма и ее вид: заявлено, присуждено, уплачено, остаток |
| Стадия | Текущее фактическое положение |
| Ближайший срок | Конкретная дата и вид срока |
| Следующее действие | Одно проверяемое действие |
| Ответственный | Конкретное лицо либо «не назначен» |
| Приоритет | Критический, высокий, средний, низкий |
| Статус подтверждения | Подтверждено, частично, требует проверки |
| Источник | Файл, ссылка, реестр или лицо, сообщившее сведения |
| Дата проверки | Дата последней фактической сверки |
| Недостающие материалы | Точный перечень |
| Примечание | Только значимые ограничения и зависимости |

## Правила заполнения

- Не оставлять неоднозначное «в работе» без стадии и следующего действия.
- Дату хранить как дату, а не как свободный текст.
- Сумму хранить числом и отдельно указывать валюту и вид суммы.
- Для неизвестного значения использовать «не установлено», а не ноль.
- Не смешивать несколько самостоятельных дел в одной строке.
- Для связанной группы дел использовать общий проект или тег, сохраняя отдельные строки.
