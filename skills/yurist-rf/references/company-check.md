# Подключение проверки российских компаний

## Обязательный специализированный навык

Для любой задачи о российской компании или ИП обязательно загрузить и применить установленный навык $check-russian-companies полностью. Он является единственным актуальным источником рабочего процесса, перечня источников, правил сверки, полей, ограничений доступа и форматов справки.

Не копировать и не пересказывать его правила внутри $yurist-rf. Обновления $check-russian-companies должны применяться автоматически без отдельного изменения настоящего навыка.

## Порядок совместной работы

1. Передать в $check-russian-companies имеющиеся ИНН, ОГРН, ОГРНИП, наименование, регион и требуемую глубину проверки.
2. Выполнить его процесс полностью, включая актуальный интернет-поиск, идентификацию лица, сверку первичных и дополнительных источников, фиксацию даты проверки, ссылок, расхождений и ограничений.
3. Сохранить в результате статусы сведений: установленный факт, сведения источника, вероятное совпадение, оценка и непроверенный раздел. Не повышать степень достоверности при переносе данных в юридический документ.
4. Для самостоятельной проверки контрагента использовать формат выдачи $check-russian-companies. Для договора, претензии, иска, заключения или судебной стратегии переносить только относящиеся к задаче сведения и отдельно выполнять юридическую оценку по $yurist-rf.
5. После объединения результатов провести обязательную приемку по $validate-legal-work-rf. Эта приемка не заменяет проверку источников по $check-russian-companies.

Пользователю достаточно вызвать $yurist-rf. Отдельно указывать $check-russian-companies не требуется.
