# Комплект судебной подачи

Запускать после утверждения содержания документа и до финальной выдачи. Не повторять правовой аудит $audit-filing-readiness; передать ему опись и контроль комплекта.

Использовать единый реестр требований из модуля references/completion-contract.md навыка $run-litigation-headquarters. До сборки определить ожидаемый состав и критерии комплектности; перед выдачей независимо сопоставить текст, опись, отдельные файлы и фактическое содержимое архива. Не засчитывать документы, которые агент лишь обещал подготовить, либо приложения только в материалах дела. Недоступное обязательное приложение фиксировать как блокер полной готовности.

1. Извлечь из текста все упоминания приложений и сопоставить с итоговой описью, порядком номеров, количеством страниц и наличием исходных файлов. Различать документ в материалах дела и документ, который фактически прилагается сейчас.
2. Для каждого приложения проверить принадлежность к нужному делу, дату, читаемость, полноту, подписи и нужную редакцию. Не редактировать содержание доказательства ради удобства сборки. При отсутствии файла отметить пробел и не включать фиктивную позицию в опись.
3. Создать копию каждого приложения отдельным файлом. Назвать по-русски, разделяя слова только обычными пробелами, без нижних подчеркиваний, дефисов и тире: «Приложение 01 [краткое содержание] [дата].[формат]». Устранить коллизии имен и сохранить сопоставление с описью. Оригиналы не переименовывать.
4. Создать архив ZIP только из реально подготовленных приложений. Проверить список файлов и открываемость архива. Сохранить основной документ отдельно и выдать обе ссылки; если приложение отсутствует, сообщить его точное название и статус. Для текста без файлов архив не создавать.
5. Для документов организаций применять официальный бланк; для суда - согласованную шапку с подтвержденной датой заседания. Проверить итоговые файлы и передать комплект на $audit-filing-readiness.

Результат: основной файл, архив приложений и контрольная опись. Не включать в архив чужие дела, промежуточные редакции и служебные файлы.
