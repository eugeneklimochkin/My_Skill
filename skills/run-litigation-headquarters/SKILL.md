# Судебный штаб

## Назначение и граница

Разложить каждую юридическую задачу на независимые проверяемые блоки, получить параллельные результаты и свести их в одну позицию. Штаб координирует работу, но не заменяет предметный навык, MASTER PROMPT 10.0, «Пять ролей» и Harvey LAB RF.

Запускать штаб для любой юридической задачи, включая короткую правку, простое письмо, отдельный пункт договора и единичный правовой вопрос. Сложность влияет только на число и специализацию агентов, но не на факт параллельного запуска.

## Обязательный параллельный запуск

До основной подготовки применять [полноту поручения и проверяемую готовность](references/completion-contract.md): заранее задать критерии, учесть все обязательные результаты, независимо проверить принятые блоки и сверить конечный комплект с актуальным заданием. Для короткого письма или одной правки использовать компактный перечень без отдельных планов; обязательный порядок агентной работы сохранять.

1. До основной подготовки результата зафиксировать поручение и одновременно запустить не менее двух независимых субагентов. Главный агент в это число не входит.
2. Для простой задачи использовать минимальную пару:
   - профильный исполнитель готовит решение или проект;
   - независимый контролер проверяет факты, право, риски, сильнейшее возражение и пригодность результата.
3. Для сложной задачи распределить между двумя-тремя одновременно работающими агентами самостоятельные блоки: факты и доказательства; право и практика; расчет, сроки, позиция оппонента либо профильный вопрос.
4. Главному агенту одновременно вести собственный анализ, координацию и последующее сведение. Не подменять параллельную работу последовательным ролевым разбором.
5. При нехватке одновременных мест использовать все доступные места в первой параллельной волне, затем запускать следующую волну для непокрытых самостоятельных блоков. Не отменять агентную проверку из-за простоты задачи.
6. Дождаться результатов всех запущенных агентов до финального сведения. При технической недоступности агента выполнить ограниченную повторную попытку; если запуск все еще невозможен, главный агент самостоятельно проверяет непокрытый блок и честно фиксирует ограничение. Не заявлять о параллельной проверке, которая не состоялась.

Обязательный запуск относится к главному агенту, который исполняет прямое поручение пользователя. Субагент действующего штаба должен выполнить назначенный блок самостоятельно и не создавать вложенный штаб, если главный агент прямо не поручил отдельную следующую волну.

## Зафиксировать штабное задание

Определить клиента, процессуальную роль, цель, стадию, адресата, сроки, материалы, требуемый документ и критерий готовности. Составить единый перечень спорных вопросов и закрытый перечень источников, доступных каждому блоку.

## Распределить блоки

Для каждой задачи выбрать минимум две непересекающиеся роли из [карты ролей](references/agent-roles.md). Для сложного дела расширить состав:

1. профильный исполнитель;
2. независимый контролер и оппонент;
3. факты и доказательства;
4. право и судебная практика;
5. расчеты и экономика требований;
6. процессуальный контроль.

Подключать предметные навыки без копирования их инструкций:

- $build-case-evidence-map для паспорта дела, хронологии и карты доказательств;
- $search-arbitration-practice для MASTER PROMPT 10.1;
- $calculate-legal-claims для расчетов;
- $control-legal-deadlines для сроков;
- $review-case-as-judge-rf для независимой проверки глазами суда;
- $control-legal-matters для реестра дел, поручений и контрольной сводки;
- $evaluate-dispute-economics для сравнения суда и урегулирования;
- профильный навык по категории спора;
- $five-roles для стратегического согласования.

## Правила независимости

- Передавать каждому блоку один ограниченный вопрос, требуемый формат и только необходимые материалы.
- Разделять роли по самостоятельным вопросам; не поручать двум агентам одинаковый пересказ материалов без отдельной цели сравнения.
- Требовать связь вывода с первичным источником, документом, страницей и датой проверки.
- Не сообщать проверяющему предполагаемый правильный ответ другого блока.
- Не поручать нескольким исполнителям одновременно редактировать один финальный документ.
- Отделять подтвержденные факты, заявления стороны, выводы, допущения и рекомендации.
- При расхождении возвращаться к источникам и критериям, а не усреднять мнения.
- Не позволять ролям подавать документы, отправлять сообщения или создавать внешние записи без прямого поручения пользователя.

## Свести результат

1. Собрать блоки в общую карту «вопрос -> факт -> доказательство -> норма -> практика -> вывод -> риск».
2. Устранить расхождения между хронологией, квалификацией, расчетом, способом защиты и просительной частью.
3. Передать сильнейшую основную и совместимую резервную позиции в $five-roles.
4. Главному агенту единолично подготовить или свести один цельный документ без отчетов ролей; для судебной задачи применить $yurist-rf-litigation.
5. Для направляемого или подаваемого документа применить $audit-filing-readiness.
6. Провести финальную атомарную приемку через $validate-legal-work-rf и MASTER PROMPT 10.0.

Не считать согласие ролей допуском документа. Статус готовности определяет только финальная приемка Harvey LAB RF.

## Запускные режимы

При командах «Новое дело», «Красная команда», «К заседанию», «Проверка перед подачей», «Отчет клиенту» или «Закрытие дела» применять соответствующий маршрут из [запускных промптов](references/launch-prompts.md).

## Выдача

Выдавать единый результат: готовый документ, позицию, план заседания или карточку дела. Внутренние отчеты блоков показывать только по прямому запросу. Если блокирующий материал отсутствует, назвать его и влияние, не восполняя пробел догадкой.
