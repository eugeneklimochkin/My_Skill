# Карта источников судебной практики

## Правило приоритета

Использовать официальный источник для подтверждения текста и реквизитов. Использовать частные интеграторы, архивы и тематические базы для обнаружения кандидатов и расширения выдачи. Если официальный текст недоступен, обозначать источник как вторичный или архивный и не скрывать предел проверки.

## Официальные источники

| Источник | Охват | Как использовать |
|---|---|---|
| [vsrf.ru/lk/practice/acts](https://vsrf.ru/lk/practice/acts) | Судебные акты Верховного Суда РФ | Искать по номеру, дате, виду судопроизводства, инстанции, виду документа, судье и фрагменту текста. Использовать как первичный источник акта ВС РФ. |
| [ras.arbitr.ru](https://ras.arbitr.ru/) | Банк решений арбитражных судов | Выполнять полнотекстовый поиск по арбитражным актам и применять фильтры по спору, суду, участнику, номеру дела и периоду. |
| [kad.arbitr.ru](https://kad.arbitr.ru/) | Картотека арбитражных дел | Проверять участников, хронологию, акты всех инстанций, отмену, новое рассмотрение и итог. Для тематического полнотекстового поиска предпочитать `ras.arbitr.ru`. |
| [sudrf.ru](https://sudrf.ru/) | ГАС РФ «Правосудие», суды общей юрисдикции и мировые судьи | Находить официальный сайт нужного суда, карточку судебного делопроизводства и опубликованные тексты актов. Проверять реквизиты по конкретному суду, а не только по центральной странице портала. |
| [mos-gorsud.ru/fastsearch](https://mos-gorsud.ru/fastsearch) | Суды общей юрисдикции города Москвы | Искать московские дела и документы по номеру, участнику, суду, категории, статье и тексту решения. Использовать как официальный источник для московских судов. |

## Дополнительные и архивные источники

| Источник | Охват | Ограничение и проверка |
|---|---|---|
| [sudact.ru](https://sudact.ru/) | Верховный Суд РФ, арбитражные суды, суды общей юрисдикции и мировые судьи | Удобный интегратор для полнотекстового и перекрестного поиска. Найденные акты проверять по официальной базе соответствующего суда. |
| [судебныерешения.рф](https://судебныерешения.рф/) | Решения и сведения по делам судов общей юрисдикции | Использовать для поиска кандидатов и дополнительных копий. Проверять по сайту суда в системе `sudrf.ru`. |
| [docs.pravo.ru](https://docs.pravo.ru/) | Судебные акты и правовые документы разных уровней | Использовать как дополнительную справочно-правовую базу. Проверять текущую доступность и подтверждать акт официальным источником. |
| [sudrf.cntd.ru/rospravo](https://sudrf.cntd.ru/rospravo) | Архив решений арбитражных судов и судов общей юрисдикции | Использовать преимущественно для исторического поиска. Не считать наличие архивной копии подтверждением текущего статуса акта. |
| [gcourts.ru](https://gcourts.ru/) | Решения судов общей юрисдикции | Использовать как дополнительный или резервный поиск. Проверять доступность и сверять найденный акт с официальным сайтом суда. |
| [media-pravo.info](https://media-pravo.info/) | Тематическая практика по информационному праву, СМИ, диффамации, рекламе, частной жизни и свободе выражения | Использовать для тематических и исторических кандидатов. Ресурс сообщает, что база не обновляется; каждый акт проверять по официальному источнику и не использовать базу для вывода о современной полноте практики. |
| [Пользовательский архив судебной практики](https://cloud.mail.ru/public/3s5Y/mkjheRpmc) | Дополнительные материалы, сохраненные пользователем | Использовать для обнаружения кандидатов и внутренних наработок. Каждый судебный акт, норму и цитату проверять по первичному источнику; материал архива не считать официальным только из-за наличия в подборке. |

## Маршрутизация

- Верховный Суд РФ: `vsrf.ru` как основной источник, затем вторичные базы для поиска дополнительных формулировок.
- Арбитражный спор: `ras.arbitr.ru` плюс `kad.arbitr.ru`, затем `sudact.ru`, `docs.pravo.ru` и архив `sudrf.cntd.ru/rospravo`.
- Суд общей юрисдикции: сайт конкретного суда через `sudrf.ru`, затем `sudact.ru`, `судебныерешения.рф` и `gcourts.ru`.
- Московский суд общей юрисдикции: `mos-gorsud.ru/fastsearch`, при необходимости сайт конкретного суда и дополнительные интеграторы.
- Исторический акт: архив `sudrf.cntd.ru/rospravo` и частные базы, затем попытка подтверждения на официальном сайте.
- Информационное право и СМИ: `media-pravo.info` для тематического обнаружения, затем обязательная официальная проверка.
- Пользовательская подборка: облачный архив для обнаружения релевантных материалов, затем обязательная проверка акта по официальной судебной системе.
