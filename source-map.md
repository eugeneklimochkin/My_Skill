# Карта источников

## Законодательство и органы власти

- Официальное опубликование нормативных актов: `publication.pravo.gov.ru`, `pravo.gov.ru`.
- Федеральные органы: официальный сайт соответствующего органа. Для налоговых вопросов использовать `nalog.gov.ru`, для закупок `zakupki.gov.ru`, для антимонопольных вопросов `fas.gov.ru`, для финансового регулирования `cbr.ru`.
- Коммерческие справочные системы использовать как средство обнаружения и удобного чтения, но юридически значимую редакцию по возможности подтверждать официальным опубликованием.

## Судебная практика

- Верховный Суд РФ: `vsrf.ru/lk/practice/acts`.
- Арбитражные суды: `ras.arbitr.ru` для полнотекстового поиска и `kad.arbitr.ru` для карточки и движения дела.
- Суды общей юрисдикции: официальный сайт суда в системе `sudrf.ru`; для Москвы также `mos-gorsud.ru/fastsearch`.
- Вторичные базы использовать для обнаружения кандидатов. Реквизиты, мотивировку и итог подтверждать официальным источником, если он доступен.

## Компании, банкротство и взыскание

- ЕГРЮЛ/ЕГРИП: `egrul.nalog.ru`.
- «Прозрачный бизнес»: `pb.nalog.ru`.
- Арбитражные дела: `kad.arbitr.ru`.
- Исполнительные производства: `fssp.gov.ru/iss/ip`.
- Существенные факты и банкротство: `fedresurs.ru`, `bankrot.fedresurs.ru`.
- Rusprofile использовать как дополнительный агрегированный источник с обязательной сверкой юридически значимых фактов.

## Правило актуальности

Если сведения способны измениться, выполнять поиск в текущем запросе. Рядом с выводом указывать дату проверки и прямую ссылку на подтверждающую страницу либо точные параметры повторного поиска.
