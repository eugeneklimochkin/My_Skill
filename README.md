# Мои навыки и инструкции для GitHub

Этот набор содержит пользовательские навыки, доступные в текущем проекте, и общие инструкции проекта. Навыки лежат в `skills/`: у каждого сохранен `SKILL.md`, вспомогательные материалы и файл `agents/openai.yaml`, если он был в исходном пакете.

## Состав

- `check-russian-companies` — Ищи, извлекай, сверяй и оформляй актуальные публичные сведения о российских юридических лицах и индивидуальных предпринимателях по ИНН, ОГРН, ОГРНИП или наименованию из официальных сервисов ФНС «Предоставление сведений из ЕГРЮЛ/ЕГРИП в электронном виде» (egrul.nalog.ru), «Прозрачный бизнес» (pb.nalog.ru), Картотеки арбитражных дел (kad.arbitr.ru), Банка данных исполнительных производств ФССП России (fssp.gov.ru/iss/ip), Федресурса и ЕФРСБ (fedresurs.ru, bankrot.fedresurs.ru), а также Rusprofile. Используй для проверки контрагента, получения свежей выписки ЕГРЮЛ/ЕГРИП и полной истории записей, поиска арбитражных, банкротных и исполнительных производств, существенных фактов и сообщений о банкротстве, подготовки краткой или расширенной справки, группового сравнения и углубленного due diligence перед сделкой, проверки активов, корпоративных цепочек, внутригрупповых операций, финансовых и налоговых данных, а также выявления расхождений между источниками.

Используй при первичном разборе большого комплекта документов, подготовке иска, отзыва, жалобы, позиции к заседанию, проверке достаточности доказательств, составлении реестра приложений или выявлении недостающих материалов.

Используй при получении судебного акта, претензии, требования, уведомления, поручения или при составлении календаря дела, проверке срока исковой давности, срока обжалования, исполнения, приемки, ответа либо подачи документа.
- `calculate-legal-claims` — Выполняй проверяемые расчеты долга, договорной неустойки, процентов, убытков, возврата аванса, госпошлины и цены иска по российскому праву. Используй при подготовке претензии, иска, отзыва, мирового соглашения, контррасчета или проверке расчета оппонента, особенно когда есть несколько платежей, периодов, ставок, лимитов или частичных погашений.

Использовать для исков, отзывов, жалоб, ходатайств, претензий, договоров, доверенностей и комплектов приложений, когда нужен итог «на подпись» и перечень блокирующих недостатков.

## Загрузка в GitHub

Распакуйте архив и загрузите содержимое папки в корень репозитория `My_Skill` через GitHub: **Add file → Upload files**. Можно также скопировать папки `skills/` и файл `AGENTS.md` в локальный клон репозитория и выполнить обычный commit/push.

Перед публикацией проверьте, что в навыках нет материалов, которые не предназначены для публичного репозитория. В этот архив не включены история Git и системные файлы кэша.
