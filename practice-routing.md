# Маршрутизация по практикам

## Основное правило

Harvey LAB RF проверяет результат, но не заменяет предметную работу. Для юридической задачи сначала применять основной навык yurist-rf и только относящиеся к категории специализированные навыки. После подготовки результата применять настоящую приемку.

## Обязательный маршрут

| Задача | Предметный навык |
|---|---|
| Любая работа по праву РФ | yurist-rf |
| Обязательная параллельная координация каждой юридической задачи | run-litigation-headquarters |
| Судебная и досудебная работа | yurist-rf-litigation |
| Стратегический выбор и проверка сильнейших возражений | five-roles |
| Большой комплект материалов и карта дела | build-case-evidence-map |
| Судебная практика | search-arbitration-practice |
| Финальная готовность к подаче или подписанию | audit-filing-readiness |
| Процессуальные, материальные и договорные сроки | control-legal-deadlines |
| Долг, проценты, неустойка, убытки, пошлина | calculate-legal-claims |
| Обязательства и контроль исполнения договора | track-contract-obligations |
| Приемка строительных и подрядных работ | analyze-construction-acceptance |
| Законы № 44-ФЗ и № 223-ФЗ | defend-public-procurement |
| Недвижимость и земля | handle-real-estate-land-rf |
| Банкротство и исполнительное производство | handle-bankruptcy-enforcement-rf |
| Проверка российского юридического лица или ИП | check-russian-companies |
| Разбор завершенного дела | learn-from-case-outcomes |

Для каждой юридической задачи независимо от сложности обязательно применять run-litigation-headquarters и одновременно запускать не менее двух независимых субагентов. Остальные предметные навыки использовать только по относимости к поручению.

Не применять это правило рекурсивно: субагент, уже выполняющий отдельный блок действующего штаба, завершает порученный блок без запуска нового штаба, если главный агент прямо не назначил следующую волну.

## Последовательность

1. yurist-rf устанавливает вид работы, источники и формат.
2. run-litigation-headquarters запускает минимум двух независимых субагентов параллельно и распределяет непересекающиеся блоки.
3. Предметный навык формирует фактическую, правовую и процессуальную модель.
4. KLS ведет работу от материалов до проекта; для судебной задачи yurist-rf-litigation подключает MASTER PROMPT 10.0 и, при необходимости, MASTER PROMPT 10.1.
5. Главный агент сводит параллельные результаты; five-roles проверяет одну общую стратегию.
6. audit-filing-readiness проверяет формальную готовность там, где документ направляется или подается.
7. Harvey LAB RF проводит итоговую атомарную приемку результата по источникам.

## Запрет дублирования

Не копировать в рубрику весь предметный навык. Извлекать из него только применимые к конкретному поручению критерии. MASTER PROMPT 10.0 хранить только в `references/arbitration-standard.md`, а MASTER PROMPT 10.1 - только в search-arbitration-practice. Для отдельного материального риска создавать отдельный критерий с указанием источника.

## Конфликт правил

При конфликте:

1. прямое поручение пользователя имеет приоритет;
2. применимая обязательная норма права имеет приоритет над шаблоном;
3. актуальные материалы задачи имеют приоритет над историческим контекстом;
4. строгий блокирующий критерий имеет приоритет над процентной диагностикой;
5. более узкий предметный стандарт дополняет базовый, но не отменяет запрет на выдуманные данные.
